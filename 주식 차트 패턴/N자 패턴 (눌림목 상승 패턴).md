## **특징 (수치적 정의)**
1. **1차 상승 → 눌림(조정) → 2차 상승**  
   - 전형적으로 **상승 → 하락(부분 조정) → 재상승** 구조  
   - 첫 번째 상승폭과 두 번째 상승폭이 유사하거나, 두 번째 상승이 더 클 수 있음

2. **눌림 구간(조정 구간)에서 지지 확인**  
   - 보통 **5일선·20일선** 등 단기·중기 이동평균선에서 지지  
   - 눌림 시 **거래량 감소** & **장대음봉 최소화**가 이상적

3. **거래량 패턴**  
   - 1차 상승 시 거래량 급증  
   - 눌림 구간에서 거래량 감소  
   - 2차 상승 구간 시작 시 재차 거래량 증가

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 1차 상승 폭
  ```python
  # 첫 번째 상승 구간: high_price[x] - low_price[x_start]
  # 상승률이 10~20% 이상이면 N자 패턴 가능성 ↑
  if (high_price[x] - low_price[x_start]) / low_price[x_start] >= 0.1:
      # 1차 상승으로 판단
```

- **조건 2**: 눌림 구간 하락률
    
    ```python
    # 눌림 구간: 주가가 5~15% 내로 하락
    if (high_price[x] - low_price[y]) / high_price[x] <= 0.15:
        # 눌림(조정) 구간
    ```
    
- **조건 3**: 지지 및 2차 상승
    
    ```python
    # 눌림 저점(y) 이후, 이전 고점(x) 대비 80~90% 수준에서 반등
    # or 5/20일 이동평균선 지지
    # 거래량도 함께 증가
    if low_price[y] > some_moving_average and volume[y_rebound] > average_volume:
        # 2차 상승 신호
    ```
    

## **활용 방법 (수치적 적용)**

1. **매수 신호**
    
    - 눌림 구간에서 이동평균선(5일·20일 등) **지지 확인**
    - 주가가 저점을 형성한 뒤, 직전 고점 대비 **80~90% 구간** 회복 시 매수
2. **손절 라인**
    
    - 눌림 저점 이하 **3~5%** 추가 하락 시 손절
    - 예시: 눌림 저점 9,500원 → 손절가 ≈ 9,225원
3. **목표가 설정**
    
    - **1차 상승폭만큼 재상승** 기대
    - 예시: 1차 상승 폭 1,000원(8,500→9,500원) → 눌림 후 2차 상승 시 **1,000원 이상 목표**

## **수치적 정리 표**

|**구간**|**기준 수치**|**예시 값**|
|---|---|---|
|**1차 상승 폭**|최초 저점 대비 **+10% 이상**|8,500원 → 9,500원 (약 12% 상승)|
|**눌림(조정) 폭**|고점 대비 **-5~15% 이내**|9,500원 → 9,000원 (약 5% 하락)|
|**2차 상승 조건**|이동평균선(5/20일 등) 지지 & 거래량 증가|지지선: 8,900원, 거래량: 전일 대비 +50%|
|**손절·익절 기준**|손절: 눌림 저점 -3~5% 익절: 1차 상승 폭|손절가: 8,730원, 목표가: 10,000원|

※ N자 패턴은 상승장이나 업종 테마 흐름이 좋은 구간에서 확률이 높으며,
   뉴스·재료·수급 등을 함께 고려하면 더욱 안정적으로 매매할 수 있습니다.
