## **특징 (수치적 정의)**
1. **첫 번째 고점 (First Peak)**
   - 상승 추세 중 형성된 최고점.
   - 고점 이후 조정으로 가격 하락.

2. **조정 저점 (Trough)**
   - 첫 번째 고점 이후 조정된 저점.
   - 저점 형성 후 다시 반등.

3. **두 번째 고점 (Second Peak)**
   - 첫 번째 고점과 유사한 수준에서 형성된 고점.
   - 첫 번째 고점 대비 **±2% 이내**의 변동 허용.

4. **완성 조건**
   - 주가가 조정 저점(Neckline)을 **3% 이상 하향 돌파**하며 거래량 증가.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 두 고점의 높이 차이가 ±2% 이내.
  ```python
  abs(first_peak - second_peak) / first_peak <= 0.02
```

- **조건 2**: 두 번째 고점에서 거래량 감소.
    
    ```python
    volume_at_second_peak < volume_at_first_peak
    ```
    
- **조건 3**: 주가가 조정 저점을 하향 돌파.
    
    ```python
    close_price < trough * 0.97
    ```
    
- **조건 4**: 하향 돌파 시 거래량 증가.
    
    ```python
    current_volume > average_volume
    ```
    

## **활용 방법 (수치적 적용)**

1. **매도 신호**
    
    - 조정 저점 하향 돌파 시 매도.
    - 예시:
        - 조정 저점(Neckline) = $50
        - 주가가 $48로 하락 시 매도.
2. **손절 라인**
    
    - 두 번째 고점보다 **2% 이상 높은 가격**에 손절 설정.
    - 손절가 = $60 × 1.02 = $61.20.
3. **목표가 설정**
    
    - 두 고점과 조정 저점 간의 차이를 기준으로 하락 목표가 설정.
    - 목표가 = 조정 저점($50) - (고점($60) - 조정 저점($50)) = $40.

## **수치적 정리 표**

|**조건**|**수치 기준**|**예시 값**|
|---|---|---|
|두 고점 높이 차이|±2% 이내|첫 고점 = $60, 두 번째 고점 = $58.80~$61.20|
|거래량 변화|두 번째 고점에서 감소|1,000,000 → 800,000|
|목선 하향 돌파|목선 대비 **3% 이상 하락**|목선 = $50, 종가 = $48|
|목표가 설정|목선 - (고점 - 목선)|$50 - ($60 - $50) = $40|



# **이중 천장 패턴 (Double Top)**

## **특징 (수치적 정의)**
1. **첫 번째 고점 (Peak 1)**
   - 상승 추세 중 첫 번째 고점을 형성.
   - 거래량이 증가하며 형성되지만, 이후 조정.

2. **두 번째 고점 (Peak 2)**
   - 첫 번째 고점과 유사한 수준에서 형성.
   - 거래량은 첫 번째 고점보다 **20% 감소**.
   - 예시:
     - 첫 번째 고점 = $100
     - 두 번째 고점 = $100 ± 2% → $98 ~ $102

3. **목선 (Neckline)**
   - 두 고점 사이의 최저점 연결.
   - 주가가 목선을 하향 돌파 시 패턴 완성.

4. **완성 조건**
   - 두 번째 고점 이후 목선을 **2% 이상 하향 돌파**.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 두 고점이 유사한 수준이어야 함.
  ```python
  abs(peak_2 - peak_1) / peak_1 <= 0.02
```

- **조건 2**: 두 번째 고점의 거래량 감소.
    
    ```python
    volume_at_peak_2 <= volume_at_peak_1 * 0.8
    ```
    
- **조건 3**: 목선 하향 돌파.
    
    ```python
    close_price < neckline * 0.98
    ```
    
- **조건 4**: 고점 간 간격 (시간 기준).
    
    - 두 고점 사이에 **최소 10일** 이상 필요.
    
    ```python
    days_between_peaks >= 10
    ```
    

## **활용 방법 (수치적 적용)**

1. **매도 신호**
    
    - 주가가 목선을 하향 돌파할 때 매도.
    - 예시:
        - 목선 = $90
        - 주가가 $88로 하락 시 매도.
2. **손절 라인**
    
    - 두 번째 고점보다 **2% 이상 높은 가격**에 손절 설정.
    - 손절가 = $100 × 1.02 = $102.
3. **목표가 설정**
    
    - 첫 번째 고점과 목선 간의 차이를 기준으로 하락 목표가 설정.
    - 목표가 = 목선($90) - (첫 번째 고점($100) - 목선($90)) = $80.

## **수치적 정리 표**

|**조건**|**수치 기준**|**예시 값**|
|---|---|---|
|두 고점 차이|첫 번째 고점 대비 ±2% 이내|첫 번째 고점 = $100, 두 번째 고점 = $98~$102|
|거래량 감소|첫 번째 고점 대비 두 번째 고점 거래량 20% 감소|1,000,000 → 800,000|
|목선 하향 돌파|목선 대비 2% 이상 하락|목선 = $90, 종가 = $88|
|고점 간 시간 간격|최소 10일 이상|첫 고점 = 1월 1일, 두 고점 = 1월 15일|
