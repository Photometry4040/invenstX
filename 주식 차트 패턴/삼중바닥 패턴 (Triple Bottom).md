## **특징 (수치적 정의)**
1. **세 번의 저점 (Three Troughs)**
   - 주가가 비슷한 수준에서 세 번의 저점을 형성.
   - 저점 간 가격 차이는 **±3% 이내**.

2. **목선 (Neckline)**
   - 세 번의 저점 이후 형성된 고점들(반등 고점)을 연결한 저항선.
   - 패턴이 완성되려면 목선을 **5% 이상 상승 돌파**.

3. **완성 조건**
   - 목선 돌파 시 거래량 증가.
   - 세 번째 저점 이후 상승 추세로 전환.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 세 저점의 높이 차이가 ±3% 이내.
  ```python
  abs(trough1 - trough2) / trough1 <= 0.03 and abs(trough2 - trough3) / trough2 <= 0.03
```

- **조건 2**: 세 번째 저점에서 거래량 증가.
    
    ```python
    volume_at_third_trough > average_volume
    ```
    
- **조건 3**: 목선 상승 돌파.
    
    ```python
    close_price > neckline * 1.05
    ```
    
- **조건 4**: 돌파 시 거래량 증가.
    
    ```python
    current_volume > average_volume * 1.5
    ```
    

## **활용 방법 (수치적 적용)**

1. **매수 신호**
    
    - 목선 돌파 시 매수.
    - 예시:
        - 목선 = $100
        - 주가가 $105로 상승 시 매수.
2. **손절 라인**
    
    - 세 번째 저점 대비 **3% 이하 가격**에 손절 설정.
    - 손절가 = $90 × 0.97 = $87.30.
3. **목표가 설정**
    
    - 목선 돌파 후 목표가는 목선과 저점 간 거리만큼 상승.
    - 목표가 = 목선($100) + (목선($100) - 저점($90)) = $110.

## **수치적 정리 표**

|**조건**|**수치 기준**|**예시 값**|
|---|---|---|
|세 저점 높이 차이|±3% 이내|저점1 = $90, 저점2 = $87.30~$92.70|
|거래량 변화|세 번째 저점에서 증가|평균 = 800,000 → 1,000,000|
|목선 상승 돌파|목선 대비 **5% 이상 상승**|목선 = $100, 종가 = $105|
|목표가 설정|목선 + (목선 - 저점)|$100 + ($100 - $90) = $110|
