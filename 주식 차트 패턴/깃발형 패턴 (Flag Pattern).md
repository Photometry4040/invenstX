## **특징 (수치적 정의)**
1. **강한 추세 전환 (Pole)**:
   - **20% 이상 급등 또는 급락** 이후 조정 구간 형성.
   - 거래량 급증 동반.

2. **조정 구간 (Flag)**:
   - 주가가 평행 사선 형태로 좁은 범위에서 조정.
   - **고점과 저점의 이격도가 ±10% 이내.**

3. **추세 재개**:
   - 조정 이후 이전 방향으로 추세 지속.
   - 돌파 시 거래량 급증.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 추세 전환이 급격할 것 (Pole 형성).
  ```python
  abs(start_price - peak_price) / start_price >= 0.2
```

- **조건 2**: 조정 구간의 형태 확인 (평행 사선).
    
    ```python
    max_flag - min_flag <= peak_price * 0.1
    ```
    
- **조건 3**: 돌파 시 거래량 증가.
    
    ```python
    breakout_volume > average_flag_volume * 1.5
    ```
    

## **활용 방법 (수치적 적용)**

1. **매수 신호**
    
    - 조정 구간 상단 돌파 시 매수.
    - 예시:
        - 조정 구간 상단 = $50
        - 주가가 $50 돌파 시 매수.
2. **손절 라인**
    
    - 조정 구간 하단 대비 **5% 이하 가격**에 손절 설정.
    - 손절가 = $45 × 0.95 = $42.75.
3. **목표가 설정**
    
    - 목표가는 추세 전환(Pole) 크기만큼 조정 구간 상단에서 추가 상승.
    - 목표가 = 조정 구간 상단($50) + (Peak - Start Price) = $50 + ($60 - $40) = $70.

## **수치적 정리 표**

|**조건**|**수치 기준**|**예시 값**|
|---|---|---|
|추세 전환 크기|급등 또는 급락 **20% 이상**|시작가 = $40, 최고가 = $60|
|조정 구간 폭|±10% 이내|상단 = $50, 하단 = $45|
|돌파 시 거래량 변화|조정 구간 평균 거래량 대비 **1.5배**|평균 = 1,000,000 → 1,500,000|
|목표가 설정|상단 + (최고가 - 시작가)|$50 + ($60 - $40) = $70|
