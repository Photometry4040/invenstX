## **특징 (수치적 정의)**
1. **왼쪽 어깨 (Left Shoulder)**
   - 상승 추세에서 첫 번째 고점 형성.
   - 거래량 증가와 함께 형성되며, 이후 조정.

2. **머리 (Head)**
   - 왼쪽 어깨보다 **10% 이상 높은 고점** 형성.
   - 거래량은 왼쪽 어깨 형성 시보다 감소.

3. **오른쪽 어깨 (Right Shoulder)**
   - 머리보다 낮고, 왼쪽 어깨와 유사한 수준의 고점 형성.
   - 거래량은 머리 형성 시보다 **30% 감소**.

4. **목선 (Neckline)**
   - 두 어깨 사이의 저점을 연결.
   - 주가가 목선을 하향 돌파 시 패턴 완성.

5. **완성 조건**
   - 주가가 목선을 **3% 이상 하향 돌파**하며 거래량 증가.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 머리의 고점이 왼쪽 어깨보다 높아야 함.
  ```python
  head > left_shoulder * 1.10
```

- **조건 2**: 오른쪽 어깨의 고점이 머리보다 낮아야 함.
    
    ```python
    right_shoulder < head
    ```
    
- **조건 3**: 오른쪽 어깨의 고점이 왼쪽 어깨와 유사한 수준이어야 함.
    
    ```python
    abs(right_shoulder - left_shoulder) / left_shoulder <= 0.02
    ```
    
- **조건 4**: 목선 하향 돌파.
    
    ```python
    close_price < neckline * 0.97
    ```
    
- **조건 5**: 거래량 변화.
    
    ```python
    volume_at_head < volume_at_left_shoulder
    volume_at_right_shoulder < volume_at_head * 0.7
    ```
    

## **활용 방법 (수치적 적용)**

1. **매도 신호**
    
    - 주가가 목선을 하향 돌파할 때 매도.
    - 예시:
        - 목선 = $50
        - 주가가 $48로 하락 시 매도.
2. **손절 라인**
    
    - 오른쪽 어깨 고점보다 **2% 이상 높은 가격**에 손절 설정.
    - 손절가 = $60 × 1.02 = $61.20.
3. **목표가 설정**
    
    - 머리와 목선 간의 차이를 기준으로 하락 목표가 설정.
    - 목표가 = 목선($50) - (머리($60) - 목선($50)) = $40.

## **특징 (수치적 정의)**
1. **좌측 어깨 (Left Shoulder)**
   - 최초의 고점 형성.
   - 거래량이 점차 증가하며 고점에 도달.

2. **머리 (Head)**
   - 좌측 어깨보다 **10% 이상 높은 고점**을 형성.
   - 거래량은 좌측 어깨 때보다 **다소 감소**.
   - 예시:
     - 좌측 어깨 고점 = $100
     - 머리 고점 = $110 (10% 상승 → 조건 만족)

3. **우측 어깨 (Right Shoulder)**
   - 머리보다 낮고, 좌측 어깨와 유사한 수준의 고점 형성.
   - 거래량은 좌측 어깨 대비 **20% 감소**.
   - 예시:
     - 우측 어깨 고점 = $101 (머리보다 낮음)
     - 우측 어깨 거래량 = 좌측 어깨 거래량의 80% 이하

4. **넥라인 (Neckline)**
   - 좌측 어깨와 우측 어깨 사이의 최저점 연결.
   - 하락 추세에서 넥라인을 하향 돌파 시 패턴 완성.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 좌측 어깨보다 머리가 10% 이상 높아야 함.
  ```python
  head_peak >= left_shoulder_peak * 1.1
```

- **조건 2**: 우측 어깨가 머리보다 낮고, 좌측 어깨와 유사한 수준일 것.
    
    ```python
    right_shoulder_peak <= head_peak
    abs(right_shoulder_peak - left_shoulder_peak) / left_shoulder_peak <= 0.05
    ```
    
- **조건 3**: 거래량 감소
    
    - 머리 거래량이 좌측 어깨 거래량보다 감소.
    - 우측 어깨 거래량이 좌측 어깨 거래량의 80% 이하.
    
    ```python
    volume_at_head <= volume_at_left_shoulder
    volume_at_right_shoulder <= volume_at_left_shoulder * 0.8
    ```
    
- **조건 4**: 넥라인 하향 돌파
    
    ```python
    close_price < neckline
    ```
    

## **활용 방법 (수치적 적용)**

1. **매도 신호**
    
    - 주가가 넥라인을 하향 돌파 시 매도.
    - 예시:
        - 넥라인 = $90
        - 주가가 $89로 하락 시 매도 실행.
2. **손절 라인**
    
    - 머리 고점보다 **2% 이상 높은 가격**에 손절 설정.
    - 손절가 = $110 × 1.02 = $112.2.
3. **목표가 설정**
    
    - 머리 고점과 넥라인 간의 차이를 기준으로 하락 목표가 설정.
    - 목표가 = 넥라인($90) - (머리($110) - 넥라인($90)) = $70.

|머리 vs 우측 어깨 차이|우측 어깨가 머리보다 낮음|머리 = $110, 우측 어깨 = $101|

|주가 넥라인 돌파|종가가 넥라인 아래일 것|종가 = $89|
