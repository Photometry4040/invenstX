
## **특징 (수치적 정의)**
1. **고점 1과 고점 2의 차이**
   - 고점 1과 고점 2의 가격 차이가 **5% 이하**일 경우 쌍봉으로 간주.
   - 예시:
     - 고점 1 = $100
     - 고점 2 = $98 (차이 2% → 조건 만족)

2. **넥라인 위치**
   - 고점 1과 고점 2 사이의 최저점(넥라인) 형성.
   - 넥라인 가격이 고점 대비 **10% 이상 하락 범위**에 위치해야 함.
   - 예시:
     - 고점 1 = $100
     - 넥라인 = $90 (10% 하락 → 조건 만족)

3. **거래량 감소**
   - 고점 2 형성 시 거래량이 고점 1 형성 시 거래량보다 **20% 이상 감소**.
   - 예시:
     - 고점 1 거래량 = 1,000,000
     - 고점 2 거래량 = 750,000 (25% 감소 → 조건 만족)

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 고점 1과 고점 2의 차이가 5% 이내일 것.  
  ```python
  abs(peak_1 - peak_2) / peak_1 <= 0.05
```

- **조건 2**: 넥라인 가격이 고점 대비 10% 이상 하락할 것.
    
    ```python
    neckline <= peak_1 * 0.9
    ```
    
- **조건 3**: 고점 2 형성 시 거래량이 고점 1 거래량보다 20% 이상 감소할 것.
    
    ```python
    volume_at_peak_2 <= volume_at_peak_1 * 0.8
    ```
    
- **조건 4**: 주가가 넥라인을 하향 돌파할 것.
    
    ```python
    close_price < neckline
    ```
    

## **활용 방법 (수치적 적용)**

1. **매도 신호**
    
    - 주가가 넥라인($90)을 하향 돌파 시 매도.
    - 예시:
        - 주가가 $89로 하락 시 매도 실행.
2. **손절 라인**
    
    - 고점 2($98)보다 **2% 이상 높은 가격**에 손절 설정.
    - 손절가 = $98 × 1.02 = $99.96.
3. **목표가 설정**
    
    - 고점과 넥라인 간의 차이를 기준으로 하락 목표가 설정.
    - 목표가 = 넥라인($90) - (고점 1($100) - 넥라인($90)) = $80.
