## **특징 (수치적 정의)**
1. **두 번의 저점(바닥)**  
   - 두 번 저점을 형성하며, 두 번째 저점이 첫 번째 저점의 가격을 하회하지 않는 경우가 많음  
   - **첫 번째 저점**: Bar_A  
   - **두 번째 저점**: Bar_B (Bar_A 대비 ±3% 이내 차이)

2. **중간 고점(Neck Line)**  
   - 두 저점 사이의 **중간 고점** 존재  
   - 해당 고점을 돌파하면 **추세 전환** 가능성↑

3. **거래량 패턴**  
   - 첫 번째 바닥 형성 후 거래량 다소 증가  
   - 두 번째 바닥 형성 시점에서 **상대적으로 거래량 감소**, 반등 시점에 거래량 급증

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 저점 간 비교
  ```python
  # 첫 번째 저점: low_price[a]
  # 두 번째 저점: low_price[b]
  abs(low_price[a] - low_price[b]) <= low_price[a] * 0.03
```

- 두 저점 가격 차이가 ±3% 이하
    
- **조건 2**: 중간 고점 발생
    
    ```python
    # Neckline: high_price[m]
    # a < m < b
    high_price[m] >= (low_price[a] + (low_price[b] - low_price[a]) * 0.5)
    ```
    
    - 중간 지점에서 상대적으로 높은 가격 형성
- **조건 3**: 거래량 변동
    
    ```python
    # 바닥 근처에서 거래량 감소, 반등 시 거래량 증가
    volume[b] < volume[a]  and  volume(breakout) > average_volume
    ```
    

## **활용 방법 (수치적 적용)**

1. **매수 신호**
    
    - 두 번째 저점(low_price[b]) 확인 후, **중간 고점(Neck Line) 돌파** 시 매수
    - 예시: Neck Line = 10,000원 → **10,000원 초과 시 매수**
2. **손절 라인**
    
    - 두 번째 저점 대비 **3~5%** 하락 시 손절
    - 예시: 두 번째 저점 9,000원 → 손절가 ≈ 8,550원
3. **목표가 설정**
    
    - Neck Line 돌파 시, **바닥 간 높이만큼 추가 상승** 가능
    - 예시: 첫 바닥 8,500원, 중간 고점 10,000원 → Neck Line 돌파 후 **1,500원** 상승 여력

## **수치적 정리 표**

|**조건**|**수치 기준**|**예시 값**|
|---|---|---|
|첫 번째·두 번째 바닥|±3% 이내 가격 차이|바닥 A: 8,700원 바닥 B: 8,600원|
|Neck Line(중간 고점)|저점~고점 * 50% 이상 높이 형성|8,700원 ~ 10,000원 사이(약 1,300원 차)|
|거래량 변동|두 번째 저점 형성 시 거래량 감소, 돌파 시 급증|바닥 구간: 거래량 80만 주 돌파 구간: 150만 주|
|손절 및 익절 기준|손절: 바닥 B 대비 -3~5% 익절: +바닥-목 간 간격|손절가: 8,550원, 목표가: 11,300원 등|

## **특징 (수치적 정의)**
1. **수렴 형태**:
   - 고점과 저점이 점점 좁아지는 형태로 수렴.
   - **상승형, 하락형, 대칭형**으로 구분.

2. **거래량 감소**:
   - 패턴 진행 중 거래량 점차 감소.
   - 패턴 돌파 시 거래량 급증.

3. **돌파 방향 중요**:
   - 상단 또는 하단 돌파에 따라 추세 지속 또는 반전.

## **판별 조건 (알고리즘 적용 기준)**
- **조건 1**: 고점과 저점이 점진적으로 수렴.
  ```python
  (peak_price[n-1] - peak_price[n]) > 0 and (low_price[n] - low_price[n-1]) > 0
```

- **조건 2**: 거래량 감소.
    
    ```python
    current_volume < average_volume
    ```
    
- **조건 3**: 돌파 시 거래량 급증.
    
    ```python
    breakout_volume > average_volume * 2
    ```
    

## **활용 방법 (수치적 적용)**

1. **매수 신호**
    
    - 상단 돌파 시 매수.
    - 예시:
        - 상단 = $100
        - 주가가 $100 돌파 시 매수.
2. **손절 라인**
    
    - 삼각형 하단 대비 **5% 이하 가격**에 손절 설정.
    - 손절가 = $90 × 0.95 = $85.5.
3. **목표가 설정**
    
    - 삼각형 높이만큼 돌파 방향으로 이동.
    - 목표가 = 상단($100) + (고점 - 저점) = $100 + ($110 - $90) = $120.

## **수치적 정리 표**

|**조건**|**수치 기준**|**예시 값**|
|---|---|---|
|패턴 수렴 여부|고점과 저점 간격 점진적 축소|고점: $110 → $100, 저점: $90 → $95|
|거래량 감소|평균 거래량 대비 감소|평균: 1,000,000 → 현재: 800,000|
|돌파 시 거래량 변화|평균 거래량 대비 **2배 증가**|평균: 1,000,000 → 돌파: 2,000,000|
|목표가 설정|상단 + (고점 - 저점)|$100 + ($110 - $90) = $120|
