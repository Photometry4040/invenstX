## 1. 개념 및 특징

엔벨로프(Envelopes)는 중심 이동평균선(주로 20일선)을 기준으로 **상·하 특정 퍼센트(%)** 범위를 설정하여 주가의 **과매수‧과매도** 구간을 시각적으로 파악하는 보조지표입니다.  
- **중심선**: 일반적으로 20일 이동평균선 사용.  
- **상단선(저항선)**: 중심선 대비 +X%  
- **하단선(지지선)**: 중심선 대비 -X%

엔벨로프 기법은 **주가가 하단 엔벨로프(과매도 구간)에 도달할 때 매수**, **상단 엔벨로프(과매수 구간)에 접근할 때 매도**하는 전략으로 알려져 있습니다.

## 2. 수치적 정의 (예시)

1. **중심 이동평균선**: 20일선  
2. **상·하단 폭(%)**: 보통 **10~20%**  
   - 예시로 **20%** 설정 시:  
     - 상단: 20일 이동평균선 * (1 + 0.20)  
     - 하단: 20일 이동평균선 * (1 - 0.20)  

3. **매수 시점**  
   - 주가가 하단선 **이탈(또는 근접)** 후 **재진입**(혹은 반등 시 양봉 발생)을 확인  
   - 분할매수 권장  
4. **매도 시점**  
   - 주가가 상단선에 **접근** 또는 **돌파**한 후 되밀림이 보이면 매도  
   - 상승 추세 강할 땐 부분 익절 후 추세 추종 가능

### 예시 규칙(알고리즘 형태)
```python
# pseudo code
envelope_percent = 20  # 20% 엔벨로프
ma_period = 20        # 20일 이동평균

for each day t:
    center_line[t] = MA(close, ma_period)[t]
    upper_line[t] = center_line[t] * (1 + envelope_percent/100)
    lower_line[t] = center_line[t] * (1 - envelope_percent/100)
    
    # 매수 조건
    if close[t] < lower_line[t] and close[t+1] > lower_line[t+1]:
        # 분할매수 시도
        
    # 매도 조건
    if close[t] > upper_line[t] or (close[t] 근접 후 하락):
        # 익절 (매도) 시도
````

## 3. 구체적인 매매 방법

1. **종목 선정**
    
    - 가급적 시가총액이 크고 유동성이 풍부(거래대금이 높은 종목)한 우량주 위주
    - **코스피 200** 등 대표 종목군 먼저 적용 시 확률 ↑
2. **분할매수**
    
    - **최초 매수**: 하단선 근처(또는 이탈 후 재돌파) → 1차 매수 40%
    - 하락 시 **2차 매수**: 추가 30% → 엔벨로프 하단선 5~10% 아래
    - **3차 매수**: 마찬가지로 5~10% 추가 하락 시 30%
3. **손절·익절 기준**
    
    - 일반적으로 **손절 없음**을 강조하나(우량주 기준),
        - 3차 매수 라인에서 -3~5% 더 하락 시 손절 권장
    - **익절**: 매수가 대비 +7~10% 구간에서 부분 매도
        - 상단선 근접 시 추가 매도 or 전량 매도
4. **참고 지표·보완**
    
    - **스토캐스틱·볼린저밴드** 등 과매수·과매도 지표 병행 시 정확도 ↑
    - 기업 펀더멘털(재무 건전성, 악재 여부) 기본 확인 필수 → “부도설, 자본잠식” 등은 제외

## 4. 실전 예시 (수치 정리)

|**구분**|**엔벨로프 하단 접근 시 수치**|**예시 값**|
|---|---|---|
|**중심선(20일)**|20일 이평선(예: 10,000원)|10,000원|
|**하단선(-20%)**|10,000원 * (1 - 0.20) = 8,000원|하단선 근처 8,000원|
|**상단선(+20%)**|10,000원 * (1 + 0.20) = 12,000원|상단선 근처 12,000원|
|**매수 조건**|종가 < 8,000원(이탈) 후다음 날 종가 > 8,000원(재돌파)|예: 7,800원 이탈 뒤8,050원 돌파|
|**매도 조건**|종가가 12,000원 접근 or 돌파 후되밀림 양상 발생|예: 12,100원 도달 후11,900원 하락|

## 5. 장단점

- **장점**
    
    - 단순 명료한 시각적 판단
    - 주가 변동 폭에 따라 자동 매매전략 수립 가능
    - 특히 **우량주** 대상 시 꾸준한 수익 기대
- **단점**
    
    - 지수 급락 시 하단선 계속 이탈 가능
    - 변동성 큰 테마주에는 잘 맞지 않을 수 있음
    - 수동적 대응 시 적절한 손절 타이밍 놓칠 우려

## 6. 요약 및 활용 Tip

- **우량주 중심으로 매수→반등→익절** 패턴에 최적화
- **엔벨로프 하단선** 접근 시 분할매수, **상단선** 접근 시 분할매도
- **큰 재료 악재(부도, 감사의견 거절 등)** 시 기법 무력화 가능
- 다른 지표(볼린저밴드, 스토캐스틱)와 병행 시 승률 향상

※ 엔벨로프 기법은 주가가 일정 범위(±20% 내)에서 움직인다는 가정 하에 
   우량주 및 장기 운용 시 높은 안정성을 기대할 수 있는 패턴.
