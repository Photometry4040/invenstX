# 강화학습 주식 거래 시스템 사용 가이드

## 투자 스타일 설정

본 시스템은 다음 세 가지 투자 스타일을 지원합니다:

### 1. 장기 투자 (Long Term)
- **특징**: 1년 이상의 장기 보유 전략
- **감마(γ)**: 0.99 (미래 보상에 높은 가중치)
- **보상 평가 기간**: 100일
- **보유 인센티브**: 0.001 (매수 후 장기 보유 유도)
- **거래 비용**: 0.002 (높은 거래 비용으로 거래 빈도 제한)
- **적합 시장**: 상승 추세 시장, 저변동성 환경

### 2. 스윙 트레이드 (Swing Trade)
- **특징**: 1주-3개월의 중단기 보유 전략
- **감마(γ)**: 0.95 (중간 수준의 미래 보상 가중치)
- **보상 평가 기간**: 20일
- **보유 인센티브**: 0.0005 (적절한 기간 홀딩 유도)
- **거래 비용**: 0.001 (중간 수준의 거래 비용)
- **적합 시장**: 변동성 있는 시장, 추세 전환 구간

### 3. 기본 트레이딩 (Default)
- **특징**: 기본 단기 트레이딩 전략
- **감마(γ)**: 0.95 (일반적인 감가율)
- **보상 평가 기간**: 5일
- **보유 인센티브**: 0.0 (홀딩 인센티브 없음)
- **거래 비용**: 0.0005 (낮은 거래 비용)
- **적합 시장**: 단기 변동성이 큰 시장, 일중 거래

## 모델 학습 방법

1. **모델 학습 시작하기**:
   - 대시보드에서 "강화학습 트레이딩 대시보드" 메뉴 선택
   - 종목 티커, 학습 기간, 투자 스타일 선택
   - "모델 학습" 버튼 클릭

2. **학습 파라미터 조정**:
   - **에포크(Epochs)**: 학습 반복 횟수 (기본값: 50)
   - **배치 크기(Batch Size)**: 한 번에 처리할 데이터 수 (기본값: 32)
   - **투자 스타일**: 위 세 가지 중 선택

3. **모델 저장 위치**:
   - 학습된 모델은 `models/[ticker]_[investment_style]_model.pth` 형식으로 저장됨
   - 모델 디렉토리는 자동으로 생성됨

## 모델 평가 및 백테스팅

1. **모델 테스트**:
   - 테스트 기간 선택 후 "모델 테스트" 버튼 클릭
   - 학습된 모델이 없을 경우 자동으로 기본 모델 사용

2. **평가 지표**:
   - **총 수익률(%)**: 투자 기간 동안의 총 수익률
   - **Buy & Hold 수익률(%)**: 단순 매수 후 보유 전략 대비 성과
   - **샤프 비율**: 위험 대비 수익률 (높을수록 좋음)
   - **거래 횟수**: 총 거래 횟수

3. **결과 시각화**:
   - 포트폴리오 가치 변화 그래프
   - 매수/매도 신호 표시된 차트
   - 개별 거래 기록 테이블

## 문제 해결 가이드

1. **테스트 결과가 매번 바뀌는 경우**:
   - 랜덤 시드가 고정되지 않아 발생하는 현상
   - 평가 모드에서 무작위성을 제거해야 함

2. **투자 스타일별 거래 횟수가 비슷한 경우**:
   - 모델 평가 시 epsilon 값이 올바르게
   - `evaluation=True` 파라미터를 사용하여 무작위성 제거 필요

3. **학습이 조기 종료되는 경우**:
   - 모델이 더 이상 성능 향상이 없는 경우 조기 종료됨
   - 성능 향상이 더디면 에포크 수 증가 고려

## 고급 설정

1. **학습 레이어 수정**:
   - `model.py` 파일의 `DQNAgent` 클래스에서 신경망 구조 조정 가능

2. **보상 함수 사용자화**:
   - `environment.py` 파일의 `step` 메서드에서 보상 함수 수정 가능

3. **기술 지표 추가**:
   - 입력 데이터에 추가 기술 지표를 포함하여 모델 성능 향상 가능
